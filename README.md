# Aluvity logo kit
svg/   vector lockups. Core logo (no tagline): horizontal (= primary, default everywhere), stacked, symbol, wordmark.
       With tagline (hero, print, decks): horizontal-tagline, stacked-tagline
png/   transparent PNGs, 2400px wide (symbol 1024px)
icons/ favicon + app icons + manifest
brand/ tokens.css, colors.json

Colourways (suffix): color = for light backgrounds, reversed = for dark backgrounds, black / white = one-colour.
Wordmark is outlined, so no font install is needed for logos.
